## Current Research Agenda
**SOP2VerifiedOpt — Provenance-Aware and Counterexample-Guided Autoformalization of Operational SOPs into Reliable Optimization Models**

核心问题：
> How can an LLM-generated optimization model be audited against the business semantics from which it was generated?

研究链条：
`SOP / Business Rules / Tables → Rule Provenance → Dual Formalization → Counterexample Audit → Verified Optimization Model → Decision & Regret`

## 部署到 GitHub Pages

1. 在 GitHub 新建公开仓库 `66661654.github.io`
2. 将本项目所有文件上传到 `main` 分支根目录
3. Settings → Pages
4. Source: Deploy from a branch
5. Branch: `main` / `(root)`
6. 保存后访问 `https://66661654.github.io/`
